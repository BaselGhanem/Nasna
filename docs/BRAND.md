# NASNA Brand Guide

## 1. Brand

| Element | Approved use |
|---|---|
| English name | **NASNA** |
| Arabic name | **ناسنا** |
| Category | **People Management Platform** |
| English tagline | **Your People. One Platform.** |
| Arabic tagline | **ناسك. منصة واحدة.** |
| Endorsement | **Powered by X Academy** |

NASNA should feel human, clear, reliable, and operationally strong. The identity avoids the cold visual language traditionally associated with legacy HR systems.

## 2. Logo Concept

The brand mark combines:

- The letter **N** from NASNA.
- Three connected points representing employees, managers, and the organization.
- One rounded container representing a unified platform.
- Rounded geometry representing accessibility and human-centered workflows.
- A dedicated Arabic wordmark built with a Thuluth-influenced calligraphic style and converted to vector paths for consistent rendering.

## 3. Color System

| Role | Color | Hex |
|---|---|---|
| Primary | NASNA Teal | `#099999` |
| Primary dark | Deep Teal | `#067979` |
| Brand ink | Deep Navy | `#142B3A` |
| Secondary text | Slate | `#647681` |
| Application background | Cloud | `#F4F8F8` |
| Surface | White | `#FFFFFF` |
| Border | Mist | `#DCE7E7` |
| Success | Green | `#168765` |
| Warning | Amber | `#C47B14` |
| Danger | Red | `#C44747` |

Teal is the identifying color. Deep navy should carry primary text and high-importance navigation. Status colors must only communicate meaning.

## 4. Typography

### English

- Primary: **Manrope**
- Fallback: **Inter**, Arial, sans-serif

### Arabic

- Primary: **Almarai**
- Fallback: Tahoma, Arial, sans-serif

Arabic and English should not be mixed within the same text run when direction handling could make the content ambiguous. Interface containers must set the correct `dir` value.

## 5. Interface Principles

- Clean information hierarchy.
- Subtle rounded containers instead of decorative lines.
- High data density without visual crowding.
- Clear approval status and audit history.
- Full RTL and LTR support.
- Mobile-first employee actions.
- Desktop-optimized administration and analytics.
- WCAG-aware contrast, focus states, and keyboard navigation.

## 6. Logo Usage

- Use the horizontal English logo in LTR interfaces.
- Use the Arabic logo in RTL Arabic interfaces, Arabic reports, and localized brand material.
- Use the square mark for favicon, mobile launcher, and compact sidebar states.
- Preserve clear space equal to one-quarter of the mark width.
- Do not recolor the mark with bright or neon colors.
- Do not stretch, rotate, outline, or add shadows to the logo.
- Do not place the primary logo over visually noisy backgrounds.
